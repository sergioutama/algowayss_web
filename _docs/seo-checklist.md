# SEO Checklist for Blog Posts

## Page Meta Tags

### Essential Meta Tags
- [ ] **Title tag**: Unique, descriptive, includes primary keyword (50-60 characters)
- [ ] **Meta description**: Compelling, includes call-to-action (150-160 characters)
- [ ] **Canonical URL**: Set to self-referencing URL
- [ ] **Viewport tag**: `<meta name="viewport" content="width=device-width, initial-scale=1">`

### OpenGraph Tags (Social Media)
- [ ] **og:title**: Same as page title
- [ ] **og:description**: Same as meta description
- [ ] **og:type**: "article"
- [ ] **og:url**: Canonical URL
- [ ] **og:image**: Featured image (1200x630px recommended)
- [ ] **og:site_name**: "Algowayss"

### Twitter Cards
- [ ] **twitter:card**: "summary_large_image"
- [ ] **twitter:title**: Same as page title
- [ ] **twitter:description**: Same as meta description
- [ ] **twitter:image**: Same as og:image
- [ ] **twitter:site**: "@algowayss" (if applicable)

## URL Structure

- [ ] **URL contains primary keyword**: Topic-relevant term in slug
- [ ] **URL uses hyphens**: Not underscores
- [ ] **URL is short and descriptive**: Under 60 characters
- [ ] **No unnecessary parameters**: Clean URLs only
- [ ] **Date-based URL structure**: Consistent with Jekyll permalink setting

## Heading Hierarchy

- [ ] **Single H1 tag**: Matching page title
- [ ] **H2 tags for major sections**: 3-5 H2s per post
- [ ] **H3-H6 for subsections**: Proper nesting hierarchy
- [ ] **Keywords in headings**: Where natural, not stuffed
- [ ] **Logical heading hierarchy**: No skipped levels (H1 → H3)

## Content Quality

- [ ] **Minimum word count**: Case studies 800+, dev-logs 500+
- [ ] **Primary keyword in first 100 words**: Natural inclusion
- [ ] **Related keywords distributed**: 3-5 terms naturally throughout
- [ ] **No keyword stuffing**: Keyword density under 2%
- [ ] **Content provides unique value**: Original insights, not duplicate
- [ ] **Outbound links**: Link to authoritative sources when relevant
- [ ] **Internal links**: Link to related blog posts

## Image Optimization

- [ ] **Descriptive file names**: e.g., "audio-compression-chart.png"
- [ ] **Alt text for all images**: Descriptive, includes keywords if relevant
- [ ] **Images compressed for web**: Under 200KB per image
- [ ] **Responsive images**: Multiple sizes for different devices
- [ ] **Image sitemap included**: In sitemap.xml if multiple images

## Technical SEO

### Indexing
- [ ] **Meta robots tag allows indexing**: `<meta name="robots" content="index, follow">`
- [ ] **Page included in sitemap.xml**: Generated by Jekyll
- [ ] **Canonical URL set correctly**: Prevents duplicate content
- [ ] **No duplicate content issues**: Unique content per URL
- [ ] **HTTPS enforced**: All URLs use HTTPS

### Performance
- [ ] **Page loads in under 3 seconds**: Core Web Vitals passing
- [ ] **Mobile-friendly design**: Responsive layout, touch-friendly
- [ ] **No intrusive interstitials**: No pop-ups blocking content
- [ ] **Font loading optimized**: Google Fonts or system fonts
- [ ] **Minified CSS/JS**: Production assets compressed

### Structured Data
- [ ] **Article schema implemented**: JSON-LD or microdata
- [ ] **Author schema included**: Person or Organization
- [ ] **Organization schema**: Company information on homepage
- [ ] **Breadcrumb schema**: Navigation path (if applicable)
- [ ] **Schema validated**: Using Google Rich Results Test

## Content-Specific

### For Case Studies
- [ ] **Problem-Solution-Result structure**: Clear narrative arc
- [ ] **Quantifiable results highlighted**: Metrics with before/after comparisons
- [ ] **Industry-specific keywords**: Relevant to target audience
- [ ] **Social proof included**: Testimonials or case references (if applicable)

### For Dev Logs
- [ ] **Technical terms explained**: Or linked to definitions
- [ ] **Before/after metrics included**: Measurable improvements shown
- [ ] **Timeline clearly presented**: When changes were made
- [ ] **Next steps defined**: What this enables

## Post-Publication

### Promotion
- [ ] **Shared on company LinkedIn**: With relevant hashtags and tagline
- [ ] **Shared on Twitter/X**: Short summary with link and image
- [ ] **Internal team notified**: Announced in team channels
- [ ] **Included in newsletter**: If email newsletter exists
- [ ] **Linked from existing posts**: Internal linking for SEO

### Monitoring
- [ ] **Google Search Console verified**: Property set up and verified
- [ ] **Ranking tracking set up**: Track keyword positions
- [ ] **Traffic monitoring active**: Analytics configured
- [ ] **Engagement metrics tracked**: Time on page, bounce rate, scroll depth
